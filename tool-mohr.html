Tool · Plane stress only

Mohr’s circlecalculator

A small tool I wrote while studying mechanics of materials. Enter a plane-stress state and it gives the centre and radius of the circle, the two principal stresses, the maximum in-plane shear and the principal angle, and draws the circle with the two state points. It covers plane stress only.

Method

The circle follows from the stress state in the usual way.

  • Centre: C = (σx + σy) / 2.
  • Radius: R = √(((σx − σy) / 2)² + τxy²).
  • Principal stresses: σ1 = C + R and σ2 = C − R, where the circle crosses the σ axis.
  • Maximum in-plane shear: τmax = R, at the top and bottom of the circle.
  • Principal angle: tan 2θp = 2τxy / (σx − σy). The angle θp runs counterclockwise from the x axis to the plane that carries σ1, and the plane that carries σ2 is 90° further round. On the circle it is half the angle from point A round to the σ1 intercept, measured clockwise.

Point A is (σx, τxy) and point B is (σy, −τxy), with τ drawn upwards. They sit at opposite ends of a diameter through C. If the circle shrinks to a point, because σx = σy and τxy = 0, every direction is principal and the page reports no angle.

I first wrote this as a small React page for my own study. This version is plain JavaScript, with no libraries and no network requests, so it runs on this static site. It also reports the principal angle, draws the τ axis at σ = 0, and uses one scale on both axes so the circle is round and the state points sit on it.

Checks

I worked two cases by hand and compared them with the calculator. The first is the starting case. The second has a negative shear and σx smaller than σy, so the principal angle falls in a different quadrant. The calculator gives the same values to two decimal places.

Limits

  • Plane stress only. The normal stress in the z direction and the shears out of the plane are taken as zero. There is no three-dimensional state and no yield criterion.
  • The maximum shear shown is the in-plane value, the radius. When σ1 and σ2 have the same sign, the largest shear in any direction is bigger, because the third principal stress is zero. This tool does not report that.
  • It does not convert units. The labels say MPa, and any one consistent unit gives consistent results.
  • It is a study aid. I checked it against hand calculations, not against other software or a design code.
