Internship · Kinematics

RT300 upper-limb retrofit

A two-layer kinematic analysis of an arm-cycling retrofit for a rehabilitation ergometer: which geometries give a useful handle motion, and which users can reach them.

Result Only the 60.4 mm short crank kept the small user in reach for the whole crank turn.
