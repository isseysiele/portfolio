# Issey Siele, Mechanical Engineering Portfolio

Static site: HTML, CSS and JavaScript. No frameworks, no tracking, nothing to build before publishing.

Live: https://isseysiele.github.io/portfolio/

## Layout

- `index.html`, `portfolio.html`, `experience.html`, `about.html`, `contact.html`: main pages
- `project-rt300.html`, `project-nosense.html`, `project-warman.html`, `project-spacecraft.html`: case studies
- `resume.html` + `resume.css`: two-page printable summary (A4)
- `styles.css`: the Drafting Studio design system
- `script.js`: navigation, reveal, videos, lightbox, chart tooltips
- `rt300-charts.js`: the two interactive charts on the RT300 page
- `linkage.js`: the live RT300 linkage on the home page and the RT300 case study
- `work.js`: search and skill filter on the Work page
- `assets/img`, `assets/video`, `assets/fonts`, `assets/og`, `assets/icons`, `assets/docs`
- `404.html`, `robots.txt`, `sitemap.xml`, `site.webmanifest`, `.nojekyll`

## Publish

GitHub Pages, deploy from branch `main`, folder `/ (root)`. Upload the contents of this folder to the repo root.

Fonts are self-hosted under the SIL Open Font License (`assets/fonts/OFL.txt`).
